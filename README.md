# Ambulance First — Professional Medical Transportation Website

A polished React + Vite landing website for **Ambulance First**, covering Air, Road and Train medical transportation.

## What was upgraded
- Animated hero with floating Air Ambulance, Road Ambulance and Train Ambulance cards.
- Animated route/orbit visual around a medical-care center.
- Connected-operations section with animated transport nodes and signal lines.
- Scroll-reveal animations for major landing-page sections.
- Hover motion and polished micro-interactions.
- Professional responsive design for desktop and mobile.
- No training/education section.
- Gallery images remain matched to Air, Road and Train transportation.
- Real-time clock/status indicators are demo UI only; connect them to a backend/API for actual live operations.

## Run
```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal, normally `http://localhost:5173/`.
